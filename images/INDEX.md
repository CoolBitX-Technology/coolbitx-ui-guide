# Image index

Generated by scripts/sync-from-drive.sh. Do not edit by hand. Images are capped at 2000 px on the long edge.

- **Tone** = mean luminance: use `dark` photos in dark/navy sections and `light` photos in light sections; `mid` can work in either, but check it.
- **cutout** = transparent PNG, which works on any surface color.
- To see them all at once, open `contact-sheet.jpg` in each product folder (labeled with file names).
- `coolwallet-s-legacy` shows a discontinued product. Use it only when the page is about CoolWallet S.
